# نبض الموسيقى العالمي — Global Music Pulse

منصة تعرض أحدث الإصدارات الموسيقية والأكثر رواجًا عالميًا، مبنية بـ
Next.js وTailwind CSS، وتعمل كموقع ويب متجاوب + PWA (يمكن تثبيتها على
الموبايل من المتصفح). البيانات تأتي مباشرة من Spotify Web API — الموقع
لا يستضيف أي ملفات صوتية.

---

## 1. الخطوة الأولى: الحصول على مفاتيح Spotify (مجاني)

1. افتح https://developer.spotify.com/dashboard وسجّل الدخول بحساب Spotify
   (أنشئ حسابًا مجانيًا إذا لم يكن لديك).
2. اضغط **Create app**.
   - App name: أي اسم (مثلاً "Global Music Pulse").
   - App description: أي وصف بسيط.
   - Redirect URI: اكتب `https://example.com` (غير مستخدم فعليًا في هذا
     المشروع لأننا نستخدم Client Credentials Flow، لكنه حقل إلزامي).
   - وافق على الشروط واضغط **Save**.
3. من صفحة التطبيق اضغط **Settings** وانسخ:
   - **Client ID**
   - **Client Secret** (اضغط "View client secret")

هذان هما المفتاحان اللي بنحتاجهما بالخطوة القادمة.

---

## 2. التشغيل المحلي (اختياري، لتجربة الموقع على جهازك قبل النشر)

يتطلب تثبيت Node.js (نسخة 18 أو أحدث) من https://nodejs.org

```bash
# داخل مجلد المشروع
npm install
cp .env.example .env.local
```

افتح `.env.local` وضع القيمتين اللي نسختهما من Spotify:

```
SPOTIFY_CLIENT_ID=القيمة_هنا
SPOTIFY_CLIENT_SECRET=القيمة_هنا
```

ثم شغّل:

```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000`

## 3. رفع المشروع إلى GitHub

```bash
git init
git add .
git commit -m "النسخة الأولى من الموقع"
```

1. أنشئ مستودع (repository) جديد فارغ على https://github.com/new
   (لا تفعّل خيار إضافة README تلقائيًا لتفادي تعارض).
2. اربط المستودع المحلي بالمستودع على GitHub (استبدل الرابط برابط مستودعك):

```bash
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git branch -M main
git push -u origin main
```

**تنبيه مهم**: ملف `.env.local` لن يُرفع أبدًا لأنه موجود في `.gitignore`
عمدًا — مفاتيحك السرية تبقى على جهازك فقط ولا تظهر على GitHub.

## 4. ربط المستودع بـ Vercel ونشر الموقع

1. افتح https://vercel.com وسجّل الدخول (يفضّل بحساب GitHub نفسه، فيربطهما
   تلقائيًا).
2. اضغط **Add New → Project**.
3. اختر المستودع اللي رفعته للتو من القائمة واضغط **Import**.
4. Vercel يكتشف تلقائيًا أنه مشروع Next.js ولا يحتاج أي إعداد إضافي
   للبناء (Build Command وOutput تُعبّأ تلقائيًا).
5. **قبل الضغط على Deploy**، افتح قسم **Environment Variables** وأضف:

   | Name | Value |
   |---|---|
   | `SPOTIFY_CLIENT_ID` | القيمة من خطوة 1 |
   | `SPOTIFY_CLIENT_SECRET` | القيمة من خطوة 1 |

6. اضغط **Deploy** وانتظر دقيقة إلى دقيقتين.
7. بعد الانتهاء، يعطيك Vercel رابطًا مباشرًا (مثل
   `your-project.vercel.app`) — هذا هو موقعك مباشرة على الإنترنت.

**كل مرة تعدّل الكود وترفعه (`git push`) لاحقًا، Vercel ينشر النسخة
الجديدة تلقائيًا خلال ثوانٍ — لا حاجة لأي خطوة يدوية إضافية.**

---

## 5. ربط دومين خاص (بعد شرائه لاحقًا)

1. اشترِ الدومين من أي مزوّد (Namecheap، GoDaddy، إلخ).
2. من داخل مشروعك على Vercel: **Settings → Domains → Add**.
3. اكتب الدومين الذي اشتريته.
4. Vercel يعطيك سجلات DNS (عادة نوع `A` أو `CNAME`) تحتاج إضافتها من
   لوحة تحكم الدومين عند المزوّد الذي اشتريت منه.
5. بعد انتشار DNS (قد يأخذ من دقائق إلى بضع ساعات)، يعمل موقعك على
   دومينك الخاص تلقائيًا مع شهادة HTTPS مجانية من Vercel.

## 6. كيف يُدار المحتوى بعد النشر؟

هذا هو الجزء المهم اللي كنا ناقشينه:

- **أحدث الإصدارات، الرائج، بيانات الفنانين**: تلقائي بالكامل. الموقع
  يطلبها من Spotify API عند كل زيارة، ويُخزّنها مؤقتًا (Cache) لمدة ساعة
  (`revalidate = 3600` في أعلى كل صفحة) لتفادي الطلبات الزائدة. لا حاجة
  لأي تدخل يدوي يوميًا.
- **إضافة قائمة رواج لدولة جديدة**: افتح `lib/constants.ts` وأضف معرّف
  قائمة تشغيل "Top 50" الخاصة بتلك الدولة من Spotify (الشرح موجود داخل
  الملف نفسه كتعليق).
- **إضافة نوع موسيقي جديد**: أضف سطرًا في مصفوفة `GENRES` بنفس الملف.
- **تعديل نصوص "من نحن" أو "الشروط"**: عدّل مباشرة داخل
  `app/about/page.tsx` و `app/privacy/page.tsx`.
- **تغيير بريد التواصل**: عدّله في `app/contact/page.tsx`.

## 7. هيكل المشروع

```
app/                    صفحات الموقع (Next.js App Router)
  page.tsx              الصفحة الرئيسية
  latest/                أحدث الإصدارات
  trending/               الأكثر رواجًا
  genre/[genre]/          صفحة نوع موسيقي (ديناميكية)
  artist/[id]/            صفحة فنان (ديناميكية)
  release/[id]/           صفحة أغنية/إصدار (ديناميكية)
  country/[code]/         صفحة رواج حسب الدولة (ديناميكية)
  search/                 البحث
  about/                  من نحن
  privacy/                سياسة الخصوصية وشروط الاستخدام
  contact/                تواصل معنا
components/              مكوّنات React قابلة لإعادة الاستخدام
lib/
  spotify.ts             كل الاتصال بـ Spotify API (مع Cache)
  constants.ts            الدول، الأنواع الموسيقية، قوائم الرواج
  types.ts                أنواع TypeScript المشتركة
```

## 8. المرحلة القادمة (غير مُنفذة بعد، حسب خطة المشروع)

- حسابات مستخدمين + قائمة مفضلة (تحتاج قاعدة بيانات مثل Supabase المجانية)
- لوحة تحكم بسيطة لاختيار المحتوى المميز في الصفحة الرئيسية يدويًا
- إشعارات عند صدور أغنية جديدة لفنان يتابعه المستخدم
